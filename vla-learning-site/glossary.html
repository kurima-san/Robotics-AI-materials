THE LANGUAGE OF ROBOT LEARNING

用語で、つまずかない。

日本語・英語・読み方から引ける72語。短い定義を確認し、詳しい章へ戻れます。

72語を表示

VLA

ブイ・エル・エー

視覚と言語を条件にロボットの行動を出すモデルの総称。身体状態や履歴を入力する場合もある。

第01章で詳しく読む →

LLM

エル・エル・エム

大規模言語モデル。文章などのトークン系列を学習し、言語に関わる生成や推定を行う。

第07章で詳しく読む →

VLM

ブイ・エル・エム

画像と言語を結びつけるモデル。画像を説明できることと精密な制御ができることは別。

第08章で詳しく読む →

Tensor

テンソル

スカラー、ベクトル、行列を含む多次元配列。各軸の意味を確認する。

第02章で詳しく読む →

Batch

バッチ

まとめて処理するサンプルの集合。

第03章で詳しく読む →

Parameter

パラメータ

学習で調整する重みやバイアスなどの数値。

第03章で詳しく読む →

Loss

ロス／損失

予測と教師や学習目標との違いを数値で表す関数。

第03章で詳しく読む →

Gradient

グラディエント／勾配

重みを変えたときの損失の変化方向と大きさを表す微分。

第03章で詳しく読む →

Backpropagation

バックプロパゲーション／誤差逆伝播

連鎖律を使い、出力側から各パラメータの勾配を求める計算。

第03章で詳しく読む →

Learning rate

ラーニング・レート／学習率

重みを更新するときの一歩の大きさ。

第03章で詳しく読む →

Epoch

エポック

学習データを一巡する単位。

第03章で詳しく読む →

Overfitting

オーバーフィッティング／過学習

学習用データへの適合に比べ、未知データでの性能が伸びない状態。

第04章で詳しく読む →

Data leakage

データリーク

評価用の情報が学習やモデル選択へ混ざり、公平な評価を損なうこと。

第04章で詳しく読む →

OOD

オー・オー・ディー

Out-of-Distribution。学習時の分布から外れる条件やデータ。

第04章で詳しく読む →

Normalization

ノーマライゼーション／正規化

数値のスケールなどを所定の規則で整える処理。推論時にも同じ規則を使う。

第02章で詳しく読む →

Token

トークン

モデルが扱う系列の単位。単語、文字、サブワードなどで、必ず一単語ではない。

第05章で詳しく読む →

Tokenizer

トークナイザー

文字列などをトークンとIDへ変換する仕組み。

第05章で詳しく読む →

Embedding

エンベディング／埋め込み

IDや入力を計算に使うベクトルへ写した表現。

第05章で詳しく読む →

Autoregressive

オートリグレッシブ／自己回帰

それまでの出力を条件に、次の要素を順次生成する方式。

第05章で詳しく読む →

Logit

ロジット

確率へ変換する前の、任意の実数のスコア。

第02章で詳しく読む →

Softmax

ソフトマックス

スコアを非負で合計1の分布へ変換する関数。

第02章で詳しく読む →

Temperature

テンペラチャー／温度

softmaxなどの分布の鋭さを調整する値。蒸留と生成の文脈を分けて考える。

第11章で詳しく読む →

Attention

アテンション

関連度に応じて他の要素の情報を重み付きで混ぜる計算。

第06章で詳しく読む →

Q / K / V

クエリ／キー／バリュー

Attentionの照合条件、照合用特徴、混ぜる情報に対応する表現。

第06章で詳しく読む →

Transformer

トランスフォーマー

Attention、MLP、残差接続などを組み合わせるニューラルネット構造。

第06章で詳しく読む →

Causal mask

コーザル・マスク

未来のトークンなど、本来見えない情報を参照させない制約。

第06章で詳しく読む →

Pretraining

プレトレーニング／事前学習

広いデータで基盤となる表現や能力を学ぶ工程。

第07章で詳しく読む →

SFT

エス・エフ・ティー

Supervised Fine-Tuning。望ましい入出力例を使う教師あり追加学習。

第07章で詳しく読む →

RLHF

アール・エル・エイチ・エフ

人のフィードバックを利用する強化学習。典型例では選好から報酬モデルを作る。

第07章で詳しく読む →

DPO

ディー・ピー・オー

Direct Preference Optimization。選好対から直接方策を調整する手法。

第07章で詳しく読む →

CNN

シー・エヌ・エヌ

畳み込みを使い局所的な特徴を処理するニューラルネット。

第08章で詳しく読む →

ViT

ビット／ブイ・アイ・ティー

Vision Transformer。画像パッチを系列として処理する画像モデル。

第08章で詳しく読む →

CLIP

クリップ

対照学習で画像と文章の対応した表現を学ぶ代表的なモデル。

第08章で詳しく読む →

RAG

ラグ

Retrieval-Augmented Generation。外部情報の検索を生成へ組み合わせる。

第09章で詳しく読む →

Agent

エージェント

目標に向け、観測・計画・実行・結果確認を繰り返すシステムの呼称。

第09章で詳しく読む →

Fine-tuning

ファインチューニング

既存モデルを追加データや目標へ適応させる学習。

第10章で詳しく読む →

LoRA

ローラ

基盤重みを固定し、低ランクの差分行列を学ぶ代表的な適応方法。

第10章で詳しく読む →

QLoRA

キューローラ

量子化した基盤重みとLoRA学習を組み合わせる方法。

第10章で詳しく読む →

Rank

ランク

LoRAでは差分を表す小さな行列の中間次元。更新の表現力と学習対象数に関係する。

第10章で詳しく読む →

Distillation

ディスティレーション／蒸留

教師の出力や特徴などを使い、生徒を学習する枠組み。

第11章で詳しく読む →

Teacher / Student

ティーチャー／スチューデント

蒸留で教師信号を出すモデルと、その信号から学ぶモデル。

第11章で詳しく読む →

KL divergence

ケー・エル・ダイバージェンス

二つの確率分布の違いを測る非対称な量。

第11章で詳しく読む →

Quantization

クオンタイゼーション／量子化

数値を少ないビットの表現へ近似すること。

第12章で詳しく読む →

KV cache

ケー・ブイ・キャッシュ

過去トークンのKeyとValueを保存して再利用する仕組み。

第12章で詳しく読む →

MoE

エム・オー・イー

Mixture of Experts。入力に応じて一部の専門家ネットワークを利用する構成。

第12章で詳しく読む →

Policy

ポリシー／方策

観測や履歴から行動を選ぶ関数または確率分布。

第13章で詳しく読む →

BC

ビー・シー

Behavior Cloning。観測と教師行動の組から方策を学ぶ模倣学習。

第13章で詳しく読む →

RL

アール・エル／強化学習

期待される累積報酬を大きくするよう行動を学ぶ枠組み。

第13章で詳しく読む →

DAgger

ダガー

自分の方策が訪れた状態への教師行動を追加し、模倣学習の分布を改善する方法。

第04章で詳しく読む →

Action space

アクション・スペース／行動空間

モデルが出す行動の種類、範囲、次元、物理的な意味。

第14章で詳しく読む →

EEF

イー・イー・エフ／エンドエフェクタ

End Effector。物体へ作用する手先。手先行動の表現では位置・姿勢などを扱う。

第14章で詳しく読む →

IK

アイ・ケー／逆運動学

目標の手先位置・姿勢を実現する関節配置を求める計算。

第14章で詳しく読む →

Proprioception

プロプリオセプション／固有感覚

関節角など、自分の身体状態に関する情報。

第14章で詳しく読む →

Action chunk

アクション・チャンク

複数の将来時刻の行動をまとめた列。

第15章で詳しく読む →

ACT

エー・シー・ティー

Action Chunking with Transformers。チャンク型の模倣学習モデル。

第15章で詳しく読む →

Prediction horizon

プレディクション・ホライズン

一回で予測する将来の長さ。

第15章で詳しく読む →

Execution horizon

エグゼキューション・ホライズン

再観測・再推論などの前に実行する行動列の長さ。

第15章で詳しく読む →

Diffusion Policy

ディフュージョン・ポリシー

条件付き拡散モデルで行動列を生成する方策。

第16章で詳しく読む →

Flow Matching

フロー・マッチング

単純な分布をデータ分布へ運ぶベクトル場を学習する枠組み。

第17章で詳しく読む →

Action expert

アクション・エキスパート

行動の生成を担当する専用のネットワーク部分を指す呼称。構造はモデルによる。

第17章で詳しく読む →

FAST

ファスト

時間的構造を利用する行動トークン化技術。

第19章で詳しく読む →

Embodiment

エンボディメント／身体性

身体構造と、観測・行動の対応を含むロボット固有の条件。

第20章で詳しく読む →

Episode

エピソード

開始から終了までの一つの試行の記録単位。

第21章で詳しく読む →

Open-loop

オープンループ／開ループ

自分の行動の結果を次の観測へ反映して修正しない評価・実行の構成。

第22章で詳しく読む →

Closed-loop

クローズドループ／閉ループ

行動の結果を観測し、次の行動を更新する構成。

第22章で詳しく読む →

Latency

レイテンシ／遅延

入力取得から出力の適用までなど、工程間にかかる時間。計測範囲を明記する。

第23章で詳しく読む →

Watchdog

ウォッチドッグ

通信や処理の停止・期限超過を監視する仕組み。

第23章で詳しく読む →

World Model

ワールドモデル／世界モデル

状態や観測と行動から、次の状態・観測・報酬などを予測するモデル。

第24章で詳しく読む →

Sim-to-Real

シム・トゥ・リアル

シミュレーションで得た能力を実世界へ移すこと。

第24章で詳しく読む →

Domain Randomization

ドメイン・ランダマイゼーション

外観や物理条件などをばらつかせ、条件変化への適応を狙う方法。

第24章で詳しく読む →

Test-time compute

テスト・タイム・コンピュート

推論時の探索、候補生成、検証などへ使う計算。

第25章で詳しく読む →

Ablation

アブレーション／除去比較

要素を外す・一つだけ変えるなどして、その寄与を調べる実験。
