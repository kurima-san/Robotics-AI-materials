PUBLISH YOUR LEARNING HUB

GitHubへ置いて、そのまま使う。

ビルド済みのHTML・CSS・JavaScriptを同梱しています。公開するだけならNode.js、npm、サーバ、APIキーは不要です。

まずローカルで開く

ZIPを展開し、index.html をChromeやEdgeなどのブラウザで開きます。すべての本文は静的HTMLです。外部フォントやCDNは使っていません。ローカルの保存制約を避ける場合は、Pythonの簡易サーバを使用できます。

cd vla-learning-site
python -m http.server 8000

ブラウザで http://localhost:8000/ を開きます。外部への通信は、出典リンクなどを自分で開く場合を除き不要です。

GitHub Pagesで公開する

  1. 空のリポジトリを作る名前の例は vla-learning-site。個人情報を含まない教材なので、公開する構成としてPublicを想定しています。Pagesの利用可否はアカウント条件も確認してください。
  2. 展開したフォルダの「中身」をpushするindex.html がリポジトリ直下に来るようにします。ZIPファイル自体を置くだけではサイトとして公開されません。ファイル数が多いため、下のGit手順が確実です。
  3. Settings → Pagesを開くBuild and deploymentのSourceを Deploy from a branch にし、Branchを main、Folderを / (root) にして保存します。
  4. 表示された公開URLを開くPagesの公開完了を確認し、トップ・章・NotebookLM取り込み専用ページを開きます。URLは https://YOURNAME.github.io/vla-learning-site/ のような形です。

GitHub公式の公開設定 ↗

git init
git add .
git commit -m "Add Japanese VLA learning site"
git branch -M main
git remote add origin https://github.com/YOURNAME/vla-learning-site.git
git push -u origin main

新規の空リポジトリを想定した例です。YOURNAMEは自分のユーザー名へ変更します。GitHub認証は自分の環境で行ってください。トークンやパスワードを教材ファイルへ書かないでください。

1ファイルだけで公開する方法

standalone.html は全28章・確認問題・操作デモ・用語集を含む単体版です。別の空リポジトリへ index.html に名前を変えて置き、同じPages設定で公開できます。この単体版は章別ファイルやMarkdownのダウンロード機能を持たないため、NotebookLMにはその公開URLか、ZIP内の教材Markdownを渡してください。

教材を追加・修正する

教材の元データは content/course.json、出典は content/sources.json です。本文・問題・答え・用語を編集し、以下を実行します。Python 3.10以上の標準ライブラリだけで生成できます。

python tools/build.py

生成されたHTMLとNotebookLM用Markdownを一緒にcommitしてください。公開時のビルドは不要です。見た目は assets/style.css、操作は assets/app.js で編集できます。

本文のsource of truthはJSONです。生成済みHTMLだけを直接編集すると、再生成でその変更が消えます。章数を増減する場合は、学習履歴の章数・クイズ数なども合わせて変更してください。

公開前の確認

教材以外の社内データ、人物が写る記録、認証情報、学習メモを含めないでください。本教材にはAPIキー、外部サービスの認証、トラッキング、ロボットを駆動する処理はありません。GitHubへのアップロードやNotebookLMでの生成は利用者が行う手順です。
