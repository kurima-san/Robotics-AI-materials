# 最初にここをお読みください

**すぐ読む：** standalone.html をブラウザで開いてください。全28章を1ファイルに収録しています。

**GitHubで公開する：** README.mdの「GitHub Pagesに公開する」を参照し、index.htmlがリポジトリ直下になるようにアップロードします。

**NotebookLMで動画にする：** まず notebooklm/chapters/01.md をソースに追加し、notebooklm/prompts/01.txt の指示を動画解説のカスタマイズ欄に貼り付けてください。サイトの notebooklm.html にも手順があります。

**全章を取り込む：** notebooklm/ALL_CHAPTERS.md または ALL_CHAPTERS.txt を使用します。URLを使う場合は公開済みの all.html を渡します。

学習履歴とメモはブラウザ内に保存する設計です。重要なメモはJSONへ書き出して保管してください。検証の範囲は TEST_REPORT.md に記載しています。

この配布物はサイトと教材です。GitHubへの公開やNotebookLMでの動画生成はまだ行っていません。
